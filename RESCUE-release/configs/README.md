# Experiment configurations

All environment-dependent paths are command-line arguments. The root README contains canonical example commands for the Qwen GSM8K pipeline.

For exact reproduction, record one command or shell script per reported experiment in this directory. Each record should include:

- model and judge-model identifiers or checkpoint versions;
- repair and clean dataset filenames;
- train/evaluation sample counts and random seed;
- optimization and mask hyperparameters;
- GPU/software environment when it affects numerical behavior.

Do not commit private filesystem paths, access tokens, or credentials.
